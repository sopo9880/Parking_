CANDIDATE release. The v16.2 SAFE_BASELINE remains protected and is not promoted automatically.

New transition refiner
----------------------
- ENTRY_TRACK_SWITCH_HOLD
  - Preserves slot-level motion context across a tracker ID switch.
  - If a new track suddenly looks stationary immediately after large slot motion, OCCUPIED confirmation is delayed until the new track is old/stable enough.
- LEAVING_WEAK_OWNER_RELEASE
  - Applies only when the baseline itself enters LEAVING.
  - Requires weak mean confidence, meaningful motion, and an EMPTY sibling vote from another CCTV for the same global slot.
  - Releases stale ghost occupancy after a short confirmation delay.
  - Requires a settle interval before baseline OCCUPIED is trusted again.
